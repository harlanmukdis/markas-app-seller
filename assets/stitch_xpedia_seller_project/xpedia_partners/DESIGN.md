## Brand & Style

This design system powers a high-density, mission-critical mobile tool for third-party marketplace merchants across Indonesia. The operational environment requires immediate legibility, high trust, and strict cognitive calm. Merchants make high-frequency decisions—fulfilling orders, tracking courier handoffs, verifying net payouts, and triaging customer disputes under tight working-day SLAs. 

The aesthetic is Modern Corporate with utilitarian ergonomics:
- **Tone:** Calm, precise, reliable, and strictly operational. Zero decorative noise, zero marketing fluff, and zero ungrounded illustrations.
- **Form Factor Focus:** Mobile-first viewport optimized for 390×844 dp with ergonomic thumb zones, minimum 48×48 dp interactive touch targets, and high-contrast typographic data grouping.
- **Language & Cultural Ergonomics:** Exclusively Bahasa Indonesia (`Pesanan`, `Produk`, `Pengiriman`, `Pendapatan`, `Performa`). Numbers adhere to Indonesian standard formatting (`Rp 2.888.100`, `98,7%`, and timestamps strictly tagged `WIB`).

## Colors

The color palette reinforces operational clarity and absolute order fidelity. No color is used arbitrarily:

- **Primary Actions:** `#0056FE` is reserved strictly for primary affirmative affordances, link navigations, active indicator dots, and tab selections. Interactive active/pressed states drop to `#0047D1`.
- **Structural Identity:** `#0F286C` anchors high-hierarchy contexts, such as system app bars, merchant header backdrops, and drawer banners.
- **Operational Status Tokens:** Status colors must always be rendered in designated background/foreground pairs. An indicator color must never appear as an isolated raw hex without its partner text tone.
  - `Processing`: `#FFF6E5` background with `#8C5002` foreground.
  - `Dalam Pengiriman`: `#EBF2FF` background with `#0047D1` foreground.
  - `Diterima`: `#E6F7FA` background with `#08677B` foreground.
  - `Selesai`: `#E8F8EF` background with `#0C7A44` foreground.
  - `Dibatalkan`: `#EFF1F4` background with `#4B5563` foreground.
  - `Perlu Tindakan`: `#FFECEE` background with `#D10C22` foreground.
  - `Pre-Order`: `#F1EEFE` background with `#6344D6` foreground.
  - `Custom Order`: `#E0D9FD` background with `#4E34AB` foreground.
- **Signature Badge:** Compact black background (`#101014`) accented with metallic golds (`#E8D08A`, `#C9A227`, `#8C6E12`). This is an earned operational recognition, never a marketing or promotional badge.

## Typography

The typography uses Inter exclusively across all layers and screens.

- **Weight Discipline:** Restrict any single card component to a maximum of 2 typographic weights (e.g., Regular 400 for structural meta and Semi-bold 600 or Bold 700 for key labels or financial amounts).
- **Legibility Boundaries:** No text element may ever drop below 11px. All metadata labels (time stamps, SLA countdown strings, product SKUs) use `label-s` or `caption` with crisp baseline metrics.
- **Numbers & Currencies:** Indonesian Rupiah amounts must always be formatted with dot groupings (`Rp 1.250.000`) using dedicated `price-*` tokens. Key performance statistics (e.g., Fulfilled Orders, Response Rate) must strictly leverage `numeric-stat` for immediate merchant parsing.

## Layout & Spacing

The layout model is mobile-first, designed around a standard screen canvas of 390×844 dp with full-bleed surfaces anchored to strict horizontal padding:

- **Canvas Metrics:** The screen horizontal margin is fixed at 16 dp (`margin: 1rem`). Internal card padding is consistently 16 dp (`space-lg: 1rem`).
- **Vertical Stack Rhythm:** Standard separation between interactive cards is 12 dp (`space-md: 0.75rem`). Structural transitions between major operational sections require 24 dp (`space-xl: 1.5rem`).
- **Micro Rhythms:** Micro spacing between text and icons follows 4 dp (`space-xs`) or 8 dp (`space-sm`).
- **Touch Ergonomics:** All touch targets must reserve an absolute minimal bounds of 48×48 dp. Control bar heights are standardized: Small controls at 36 dp, Medium at 44 dp, Large CTA buttons at 52 dp, App Bar at 56 dp, and Bottom Navigation fixed at 64 dp.

## Elevation & Depth

Visual hierarchy prioritizes crisp borders and tonal contrast over blur-heavy drop shadows:

- **Border-Driven Depth:** Cards and list containers rest on `#F7F8FA` (bg-canvas) using `#FFFFFF` (bg-surface) bounded by a crisp 1 dp hairline stroke of `#E5E7EB` (border-subtle). No card should carry heavy or soft drop shadows.
- **Focus States:** High-contrast focus boundaries expand to 2 dp `#0056FE` without glowing radial halos.
- **Elevated Modals:** Floating elements, such as persistent modal bottom sheets and contextual dialogs, use subtle, non-intrusive elevation: `0 8px 24px rgba(17, 24, 39, 0.12)`.

## Shapes

The geometric vocabulary balances clean modern tech with structured enterprise density:

- **Cards & Primary Buttons:** Master corner radius is standard 8 dp (`roundedness: 2`), ensuring a disciplined structural cadence on handheld viewports.
- **Badges & Status Chips:** Fully rounded pills (`border-radius: 9999px`) provide clear contrast against rectangular card frames.
- **Input Fields & Small Controls:** 8 dp corner radius maintains alignment across forms and filter panels.
- **Sheet Corners:** Top edges of persistent bottom sheets scale to 16 dp or 24 dp (`rounded-xl` to `rounded-2xl`) for a smooth resting envelope.

## Components

### Buttons
- **Primary:** Background `#0056FE`, text `#FFFFFF`, border-radius 8 dp. Height: 52 dp for fixed bottom action bars; 44 dp for contextual body triggers. Pressed state drops to `#0047D1`.
- **Secondary:** Background `#FFFFFF`, border 1 dp `#D1D5DB`, text `#111827`, border-radius 8 dp.
- **Danger:** Background `#FB132D`, text `#FFFFFF`, border-radius 8 dp. Used exclusively for irreversible actions such as `Tolak Pesanan`.
- **Ghost:** Background transparent, text `#0056FE`, hover/pressed background `#EBF2FF`.

### Status Chips & Badges
- Pill-shaped container, height 24 dp, horizontal padding 8 dp, `label-m` (12px, weight 500).
- Must always match authorized status background and foreground token pairings. A bare colored dot with no text is prohibited.
- **SLA Countdown Badge:** Renders inside order cards when fulfillment remaining window is < 24 hours. Formatted as `Sisa 14 jam` with a warning or danger token pairing.

### Order Cards
- Container: Surface `#FFFFFF`, 1 dp border `#E5E7EB`, padding 16 dp, border-radius 8 dp.
- Layout hierarchy (top-to-bottom):
  1. Order ID (e.g., `#XP-89210`) aligned left; Status Chip aligned right.
  2. Buyer Information: Masked identifier (e.g., `D******`) + Destination City (e.g., `Jakarta Barat`). Full address, email, and phone must remain strictly hidden.
  3. Product Row: 48×48 dp image thumbnail, product title (`title-l` truncated to 1 line), item count (e.g., `1 barang`).
  4. Total Order Price (`price-m`, e.g., `Rp 145.000`).
  5. SLA Countdown Chip (if under 24 hours).
  6. Action CTA: Default operational action is `Cetak Resi` (Primary button). Do not place a `Terima Pesanan` action. The rejection action `Tolak Pesanan` is styled Danger.

### Payout & Earnings Breakdown Panel
- Clean vertical stack detailing net transaction values in strict sequential order:
  1. `Total Nilai Barang`
  2. `Support Ongkir Seller`
  3. `Komisi Xpedia 5%`
  4. `Xpedia Growth` (if enabled, commission tier 1%–15%; never use the words ads/iklan)
  5. `Biaya Layanan`
  6. `Total Pendapatan Seller` (bold, `price-l`, highlighted with `#0F286C`)
  Lines with Rp 0 must be explicitly printed rather than hidden.

### Bottom Navigation
- Fixed height: 64 dp. Background `#FFFFFF` with 1 dp `#E5E7EB` top border.
- Maximum 5 primary destinations (`Pesanan`, `Produk`, `Chat`, `Pendapatan`, `Lainnya`).
- Active items use `#0056FE`; inactive items use `#6B7280`. Notification badges use `#FB132D` with `#FFFFFF` text.
